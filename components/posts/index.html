post Section Patterns

Twelve in-post section patterns ported from the Batik design system into si-es-es.css. Each block re-tints per category.

Back Components Home → The full component catalog.

How to Use these Patterns

  • Wrap a run of post sections in an element with data-category="work|life|balance". The --cat-* tokens cascade down and re-tint every block below.
  • Each pattern is a single class on the section wrapper (e.g. .post-figure). The wrapper caps to the 1140px column and pads it; inner elements set their own measures.
  • Glyphs use Lucide icon-*; brand marks use Simple Icons brand-*.

The specimens below run in a data-category="work" wrapper, with one data-category="balance" block near the end to show category theming.
