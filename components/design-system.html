Design System

The house style for rudzainy.my, codified as design tokens in si-es-es.css. Everything below is rendered live from those tokens — change a value at :root and it propagates across the whole site. Palette: Batik (indigo / emerald / saffron on songket cream).

← Back to component catalog

Palette

Each category ships a vivid base (backgrounds, accents) and a darkened -ink variant (heading text on white/cream) so contrast holds in both roles. The category colours are consumed through Bootstrap utility classes in the markup, so :root remaps --bs-info/success/warning/primary onto these tokens.
