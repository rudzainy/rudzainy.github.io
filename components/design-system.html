Section header

The in-post section opener: a solid category tab sitting on a 2px rule, like a file divider, so the line opens the section instead of closing the last one. Classes: .post-section-head + .head-tab, modifiers .is-first and .is-inverse.

How to Use this Pattern

  • Two sibling elements: div.post-section-head immediately followed by the <h2> it introduces. Nothing may sit between them; the CSS uses +.
  • The wrapper carries aria-hidden="true": the tab is decorative garnish, and the h2 alone carries the section's accessible name and keeps its existing id= anchor. The h2 itself gains no class.
  • The tab holds a zero-padded number, one Lucide icon-* glyph naming the section's subject, and an optional lowercase kicker after &middot;. Kicker or no-kicker is decided per post, never mixed inside one.
  • Colour rides the inherited --cat-* tokens: a data-category wrapper, or the .page-header-* bridge that every served post already carries.
  • .is-first drops the top margin on the first section of a case study. .is-inverse flips the tab to white-on-ink for the one head that sits on a dark category ground.

The three forms below are shown twice, once in a data-category="work" wrapper and once in data-category="life", so the tab, rule and heading re-tint with no per-block changes.
