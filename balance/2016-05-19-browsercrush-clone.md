<h2 id="setup">Setup</h2>
<ol>
  <li>Download the source files.</li>
  <li>Run <code>$ bundle install</code>.</li>
  <li>Run <code>$ ruby app.rb</code>.</li>
  <li>Open a web browser and type in <code>localhost:4567</code> in the address bar.</li>
  <li>Enjoy the game!</li>
</ol>
